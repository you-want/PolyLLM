# PolyLLM `v0.4.0`

> 发布版本：0.4.0；npm / PyPI 待发布。

`v0.4.0` 是 PolyLLM 的稳定协议版本：统一双语言协议语义、可判断的供应商错误、可控的请求生命周期（超时/取消/重试），以及跨语言一致性门禁。9 个 npm 包与 7 个 Python 包同步到 `0.4.0`。

## 协议与一致性

- 语言无关 JSON 契约：统一序列化使用 camelCase，Python 用户 API 保留原生 snake_case；字段缺省/null/未知值规则在 [protocol.md](../protocol.md) 冻结。
- 跨语言协议门禁（`pnpm verify:protocol`）：共享 fixtures 覆盖请求/响应/流分片/工具/错误/超时/JSON Mode，TypeScript 与 Python 输出逐字段 diff。
- 流式 delta：Python 增加 `StreamDelta` 属性访问（`content` / `role` / `tool_calls`），原有 dict 下标访问保持兼容。
- 能力缺失从静默忽略改为报错：对 `vision=false` 模型传 `image_url`、对 `jsonMode=false` 模型设 `jsonMode=true` 统一抛 `UNSUPPORTED_PARAMETER`（`details` 含 `parameter`）。
- usage 缺省归零 + 标记：供应商未返回 usage 时 `usage` 恒为零值，`providerMetadata.usageUnavailable = true`。

详见 [迁移指南](../migrations/v0.3-to-v0.4.md) 与 [能力矩阵](../compatibility.md)。

## 可判断的错误

- 供应商错误保留 `code = PROVIDER_ERROR`（0.3.0 兼容），`details` 新增可选结构化字段：`category`（`auth` / `permission` / `rate_limited` / `server` / `connection` / `invalid_response` / `timeout` / `cancelled`）、`retryable`、`requestId`、`retryAfterSeconds`。
- 401/403/429/5xx、连接失败、无效 JSON、流中错误均有确定映射；未知状态保留兜底。
- 诊断字段不复制未经筛选的 headers / URL query / 响应 body；错误消息与详情不泄漏测试凭据。

## 超时、取消与显式重试

- `timeoutMs` / `timeout_ms` 是**整个调用总预算**（含重试、退避、流读取），不是单次尝试预算。
- 取消/超时后本端保证释放 reader/连接/timer；Python 官方插件默认 transport 在 task 取消时先关闭活动 socket，再传播 `asyncio.CancelledError`。
- 重试**默认关闭**（行为与 0.3.0 一致，升级不会自动增加调用次数/费用）。需要重试时显式传策略：

```ts
// TypeScript
const resp = await llm.chat(model, { messages }, {
  retries: { maxAttempts: 3, baseDelayMs: 500, jitter: 0.25 },
})
```

```python
# Python
resp = await llm.chat(model, {"messages": messages},
                      retries={"maxAttempts": 3, "baseDelayMs": 500},
                      timeout_ms=30_000)
```

- Python 新增公共原语 `with_retries` / `compute_backoff_ms` / `max_attempts`；独立使用时从返回 dict 的 `result` 读取结果，不要再包裹已启用 `retries` 的公开调用以免叠加重试。

## Studio / CLI 生成器

- 生成项目依赖版本约束升到 `0.4.0`（npm `^0.4.0`，Python `>=0.4.0,<0.5.0`）。
- `new-plugin` 脚手架生成的插件骨架包含 0.4.0 错误分类与重试模板，跟随 `PROVIDER_ERROR` `details.category` / `retryable` 语义。

## 明确未做（P1 延期，见 [计划 §11](../plans/v0.4.0-plan.md)）

- Gemini base64 图片输入：维持 `vision=false`，不引入 data URL/base64 映射，留待后续版本。
- npm 标签预检与恢复提示强化：`promote-npm-dist-tag` 现有逐包提升逻辑保持，并发保护与部分成功恢复在发布阶段单独评估。
- 模型发现（`listModels`）接入统一超时选项：保持插件自身默认，是否纳入下一版发布时评估。

## 安装

```bash
npm install @you-want/polyllm-core @you-want/polyllm-openai-compatible
```

```bash
python -m pip install polyllm-core polyllm-openai-compatible
```
