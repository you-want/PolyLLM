# PolyLLM `v0.2.0`（开发中）

`v0.2.0` 将 PolyLLM Studio 从配置生成器升级为可直接交付项目的本地初始化工具。

## Studio

- 支持 TypeScript 与 Python 项目生成。
- 支持 npm、pnpm、yarn 与 pip。
- 支持完整文件树与单文件源码预览。
- 支持导入 `polyllm.config.json`、继续编辑并恢复本地缓存。
- 支持浏览器本地生成并下载完整项目 ZIP。
- API Key 继续只保存在浏览器会话中，不进入配置、源码或 ZIP。

## 生成项目

- TypeScript：生成 `package.json`、`tsconfig.json`、LLM 模块和可运行入口。
- Python：生成 `pyproject.toml`、src-layout 包、LLM 模块和异步入口。
- Studio 与 CLI 共用 `@you-want/polyllm-studio` 的统一项目生成器。
- 旧版 `polyllm.config.json` 可继续导入，缺失的项目元数据使用安全默认值。

## 质量门禁

- 自动生成 TypeScript 项目并执行真实 `tsc` 编译。
- 自动生成 Python 项目并验证 TOML、源码编译和客户端导入。
- 浏览器端到端覆盖语言切换、ZIP 下载、配置导入与刷新缓存。
