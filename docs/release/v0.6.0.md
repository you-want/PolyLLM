# PolyLLM `v0.6.0`

> 发布版本：0.6.0；npm / PyPI 已完成发布（2026-10-25）。release commit `ed7b449`，tag `v0.6.0`。

`v0.6.0` 是实验功能版：引入离线接入诊断（`polyllm diagnose`），新增 `@you-want/polyllm-diagnostics` 包。10 个 npm 包与 7 个 Python 包同步到 `0.6.0`。诊断功能整体处于实验状态，报告 Schema（`0.1.0-draft`）不受稳定 API 承诺保护。

## 离线接入诊断（实验）

面向「普通聊天可用，但工具调用、参数或流式行为异常」的故障场景：

- 新包 `@you-want/polyllm-diagnostics`：独立参考累积器（直接按 OpenAI 流式规范实现，不依赖 `polyllm-core`——诊断器不同时担任被测对象与裁判）、稳定异常码（`STREAM_PARSE_MISSING_INDEX` 等 6 个）、版本化 JSON 报告（`schemaVersion: 0.1.0-draft`）。
- CLI 新命令：`polyllm diagnose --fixture <file|dir> [--out <dir>] [--quiet]`。输入脱敏 fixture（原始 SSE 事件序列 + 期望），输出分层结论（request-mapping / upstream-response / stream-parse / normalization）与可重放证据。**纯离线：无网络请求、无凭据、无遥测**。
- 现有 `doctor`、`models`、`init`、`studio`、`new-plugin` 行为不变。
- 5 个来自公开案例的脱敏 fixture（工具增量显式 null、缺 `index`、并行调用恒 `index=0`、参数泄漏为 content、标准续帧基线）随包重放，变异检查（5 条故意损坏流全部被拒）防止「报告永远绿」。

## Rust 探索（随本版入库，不发布）

`rust/` 目录进入仓库：第三语言实现消费与 TS/Python 相同的共享协议 fixture（`fixtures/protocol/*.json`），含注册表、参数策略、客户端与 OpenAI Chat Completions 适配器。28 项测试 + clippy 零警告 + CI 门禁（`.github/workflows/rust.yml`）。**实验性：不发布 crates.io、不进 npm/PyPI 发布范围、不受稳定 API 承诺保护。**

## Python 端

7 个包仅版本同步到 `0.6.0`，无功能变化。
