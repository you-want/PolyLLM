# PolyLLM `v0.1.0`

发布日期：2026 年 9 月 17 日

`v0.1.0` 是 PolyLLM 的首个公开 MVP 版本，完成了从统一协议、供应商插件到本地 Studio、CLI 和公共 registry 发布的最小闭环。

## 已发布包

- npm：`@you-want/polyllm-core`、`@you-want/polyllm-openai`、`@you-want/polyllm-openai-compatible`、`@you-want/polyllm-deepseek`、`@you-want/polyllm-anthropic`
- PyPI：`polyllm-core`、`polyllm-openai`、`polyllm-openai-compatible`、`polyllm-deepseek`、`polyllm-anthropic`

## 主要能力

- 统一聊天请求、响应、流式响应和模型描述协议。
- OpenAI、DeepSeek、Anthropic 与 OpenAI-compatible 插件化接入。
- `provider:model` 模型命名空间、别名解析、动态自定义模型和参数策略。
- Studio 本地配置 API Key、Base URL、模型发现、模型选择和项目生成。
- CLI 初始化 TypeScript 项目，并保持密钥不写入生成物。
- npm 与 PyPI 的构建、元数据、打包安装、类型和导入验收。

## 安装

```bash
npm install @you-want/polyllm-core @you-want/polyllm-openai
```

```bash
python -m pip install polyllm-core polyllm-openai
```

发布包的独立用户示例见 `examples/published/`。
